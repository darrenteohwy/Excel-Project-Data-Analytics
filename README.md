# Data Jobs Dashboards Portfolio

A portfolio showcasing two dashboards analyzing real-world data science job salaries using **Excel** and **Power BI**, providing insights into salaries, skills, and job trends.

---

## Project 1 – Excel Salary Dashboard

![Project 1 Data Science Salary Calculator](images/Project%201%20Data%20Science%20Salary%20Calculator.png)


**Introduction:** Explore salaries for data roles and assess compensation fairness using a 2023 dataset of job titles, salaries, locations, and skills.

**Dashboard File:** [Project 1 - Excel Dashboard for Data Science Job Salaries Practice.xlsx](./Project%201%20-%20Excel%20Dashboard%20for%20Data%20Science%20Job%20Salaries%20Practice.xlsx).

**Skills Used:** 📉 Charts | 🧮 Formulas | ❎ Data Validation

**Key Features:**
- **Bar Chart:** Median salaries by job title.  
- **Map Chart:** Median salaries by country.  
- **Formulas:** Multi-criteria median salary calculations & unique job type listing.  
- **Data Validation:** Ensures consistent inputs.

**Insights:** Senior roles and specialized skills command higher salaries; geographic disparities exist.
